## Repositorio de Evidencias y Documentación
# Descripción

Este repositorio tiene como propósito almacenar y organizar la documentación, evidencias y entregables generados durante el desarrollo de prácticas, proyectos académicos y actividades relacionadas con la materia.

Aquí se incluyen capturas de pantalla, reportes, diagramas, documentos técnicos y demás archivos que sirven como evidencia del trabajo realizado.

# Objetivo

Mantener un registro ordenado y accesible de las actividades desarrolladas, permitiendo consultar el progreso, resultados y documentación de cada práctica o proyecto.
